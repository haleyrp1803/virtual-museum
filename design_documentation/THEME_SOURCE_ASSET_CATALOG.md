# Theme Source Asset Catalog

## Purpose

This catalog records the organized source-asset library added for development design studies. These files are licensed or public-domain source references. Optimized WebP derivatives used by the live application remain under `public/assets/themes/textures/`.

## Folder conventions

```text
public/assets/
├── design-references/notebook/
└── themes/
    ├── source-assets/
    │   ├── shared-materials/
    │   ├── jim-crow/
    │   ├── world-wars/
    │   ├── civil-rights/
    │   ├── modern-schooling/
    │   └── course-neutral/notebook/
    └── textures/
        ├── colonial/
        ├── victorian/
        ├── jim-crow/
        ├── world-wars/
        ├── civil-rights/
        ├── modern-schooling/
        └── course-neutral/
```

- `source-assets/` preserves the original licensed or public-domain source file under a descriptive filename.
- `textures/<era>/` contains optimized derivatives actually used by CSS.
- Shared neutral materials are stored once in `source-assets/shared-materials/` and may support more than one era.
- Notebook product photographs are design references, not live site assets.
- Bright 1960s–1970s patterns belong exclusively to the Civil Rights design pack.
